# asteriod-knn-classification
Final Project for ASTRO 416 at UMich

This repository includes:
A Jupyter notebook documenting all my work and discussions of it

A zipfile of data I used for this project, which contains
- meanspectra.tab, from the DeMeo et. al. 2009 data archive. This is the mean spectra for all spectral types
- demeotax.tab, from the DeMeo et. al. 2009 data archive. This is the list of asteroids used to define the taxonomy, plus their spectral type
- asteroids.fits, from the Gaia database. This is all the asteroid spectra available from Gaia archive.

Data used is from

DeMeo et. al. 2009 <br>
Gaia Collaboration et. al. 2023
